# vtitek

Сайт-визитка студии веб-разработки vtitek. Чистые HTML/CSS/JS без сборки.

## Запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для публикации подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel): загрузите файлы как есть.

## Что заменить перед запуском

- Контакты: `https://t.me/vtitek` и `hello@vtitek.ru` в `index.html` и `script.js`.
- Портфолио, отзывы, цифры в hero и цены — сейчас это демо-контент.
- Форма заявки без бэкенда открывает почтовый клиент; для заявок в Telegram нужен небольшой серверный обработчик.
